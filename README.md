# Рейтинг карт S/A/B/C/D

## Установка
Замените app.js и index.html. Добавьте ratings.css рядом со styles.css. Не удаляйте существующий styles.css, data/cards.csv и изображения. Архив является обновлением, а не полным проектом.

## Совместимость CSV
Существующий CSV работает без изменений. Если столбца rating нет, все карты изначально без рейтинга. Набор deck (S/A/B/C) и оценка rating (S/A/B/C/D) независимы. Рейтинг не назначается автоматически.

## Оценивание
Откройте карту, выберите оценку и нажмите «Сохранить рейтинг». Изменения хранятся в localStorage этого браузера для текущего адреса сайта. «Без рейтинга» снимает оценку. «Вернуть из CSV» удаляет личное переопределение и восстанавливает исходную оценку из файла.

Личные оценки имеют приоритет над CSV. При изменении CSV снаружи нажмите «Вернуть из CSV» у карты, если хотите использовать новое значение файла. При недоступном хранилище изменения остаются только в текущей вкладке: экспортируйте CSV до её закрытия.

## Публикация оценок
Нажмите «Экспорт CSV с рейтингами». Экспортируются ВСЕ загруженные карты, а не только отфильтрованные. Файл включает box и rating, учитывает личные изменения. Замените им data/cards.csv локально или в репозитории GitHub. Сайт сам не отправляет изменения в GitHub. Посетители без личных переопределений увидят рейтинг из опубликованного CSV.

Заголовок экспортируемого файла:
```csv
id,name,deck,type,power,description,image,box,rating
```

Допустимые значения rating: S, A, B, C, D или пустая строка. S — лучшие; D — плохие. Карты без оценки идут последними при сортировке по рейтингу. Старый CSV без box считается первой коробкой; для двух коробок сохраняйте box=base/beach.

Продолжайте запускать через HTTP-сервер, например python -m http.server 8000 --bind 127.0.0.1.
