# Challengers — каталог карт

Статический сайт без сборки, npm, сервера приложения и внешних библиотек. Источник данных — `data/cards.csv`, изображения находятся в `images/`. Каталог не редактируется в браузере: изменения вносятся в файлы репозитория.

## Структура

```text
index.html
styles.css
app.js
.nojekyll
data/
  cards.csv
images/
  Zatonuvshii-korabl_Kok.jpg
  Gorod_Zakusochnaia-na-kolesakh.jpg
```

## Публикация на GitHub Pages

1. Создайте репозиторий GitHub или используйте существующий.
2. Распакуйте архив и загрузите СОДЕРЖИМОЕ папки `challengers-site` в корень репозитория. Файл `index.html` должен находиться непосредственно в корне.
3. Сохраните изменения (commit).
4. Откройте Settings → Pages. В Build and deployment выберите Deploy from a branch, вашу основную ветку (обычно `main`) и папку `/ (root)`, затем Save.
5. Дождитесь завершения публикации. Адрес опубликованного сайта появится в разделе Pages.

Все пути относительные: сайт рассчитан и на страницы проекта, расположенные в подпапке репозитория. Не добавляйте начальный `/` к путям изображений.

## Добавление карты

1. Поместите PNG, JPG или WebP в `images/`. Можно создавать вложенные папки.
2. Добавьте строку в `data/cards.csv`.
3. Сохраните оба изменения в GitHub. После повторной публикации обновите страницу.

Пример:

```csv
id,name,deck,type,power,description,image
kok,Кок,B,Затонувший корабль,2,"На скамье: ваша карта, обладающая флагом, получает +1 к силе.",images/Zatonuvshii-korabl_Kok.jpg
```

| Столбец | Назначение |
|---|---|
| id | Уникальный непустой идентификатор |
| name | Название карты |
| deck | Только S, A, B или C |
| type | Тип / тематическая колода, например Город |
| power | Базовая сила, число от 0; можно оставить пустым |
| description | Текст эффекта; можно оставить пустым |
| image | Путь от корня сайта, начинающийся с images/ |

Под «типом» понимается тематическая колода. Если нужна другая классификация, значения type можно заменить своими.

Имена файлов могут соответствовать схеме `Название колоды_Название карты.png`, но сайт использует явный путь из CSV, а не разбирает имя. Кириллица и пробелы поддерживаются. Регистр букв должен совпадать с именем файла. Для простоты предпочтительны имена без знаков `?` и `#`.

## Формат CSV

- Кодировка UTF-8 (BOM допустим).
- Разделитель — запятая. Также поддерживается точка с запятой, если заголовок целиком использует этот разделитель.
- Текст с запятыми, переводами строк или кавычками заключайте в двойные кавычки.
- Кавычка внутри такого поля удваивается: `"Эффект: ""пример""."`.
- Не меняйте названия заголовков. При ошибке сайт покажет сообщение вместо неполного каталога.
- При работе в Excel сохраняйте как CSV UTF-8; после сохранения проверьте заголовки.

## Локальная проверка

В папке проекта, если установлен Python:

```sh
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. На некоторых системах команда называется `python3`.
Двойной щелчок по index.html не подходит: браузер может заблокировать загрузку CSV через fetch.

## Возможности

Поиск по названию, типу и описанию; фильтры S/A/B/C и типов; сортировка по имени, набору, типу и базовой силе; увеличенный просмотр и полное описание; адаптивная сетка. Добавление типа в CSV автоматически добавляет его в фильтр. Данные читаются из репозитория при загрузке страницы, localStorage не используется.

## Права

Неофициальный каталог. Перед публичной публикацией убедитесь, что имеете право размещать изображения и тексты карт. В архив включены два предоставленных пользователем примера.
